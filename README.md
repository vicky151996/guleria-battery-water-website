# Guleria Battery Water Website

A responsive, production-ready enterprise landing page and commercial platform built to showcase products and manage local client operations for a battery water manufacturing utility. 

## 🚀 Live Demo
[👉 Click here to view the live website](https://vermillion-pika-d3c808.netlify.app/)

## 🛠️ Technical Stack
* **Architecture:** Semantic HTML5, CSS3 Layout Modules
* **Interactivity:** JavaScript (ES6+ Viewport Logic)
* **Design Methodology:** Mobile-First Responsive Design, Flexbox Grid
* **Version Control:** Git, GitHub Pages

## 💎 Key Features
* **Optimized Product Catalog:** Clean grid architecture highlighting product tiers, purity standards, and technical specifications.
* **Fluid Response Framework:** Cross-platform layout consistency tested across mobile viewports, tablets, and desktop displays.
* **Interactive Navigation:** Smooth JavaScript-driven scroll components and dynamic modal event handlers.
* **SEO & Semantics:** Structured markup hierarchy to ensure high accessibility scores and clean indexing.

## 🔧 Local Development & Setup

To review the layout and code repository structure locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd guleria-battery-water-website
   ```

2. **Run the project:**
   Simply open the `index.html` file directly in any modern web browser, or use the **Live Server** extension in VS Code.
